# Irish Studies

Games and lessons for Irish mythology, history, geography, culture and the Irish language (Gaeilge). Part of the homeschool adventures; uses the unified family code and syncs with Harbor.

- Live: https://irish.jacobsiler.com
- Deploy: double-click `push.cmd` (or run `scripts\ir-start-watcher.cmd` and tick `deploy-tick.txt`).
- Progress is saved to Firestore `families/{CODE}_ir` so Harbor can show it.
- Add content with `IR.addUnit({...})` in `ir-gaeilge.js`, `ir-culture.js`, `ir-places.js`.
